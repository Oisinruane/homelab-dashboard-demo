# Overview

## What this is

A static export of the demo/mock-data mode of my private `homelab-dashboard` project. The
private version runs on my home server and talks to real services over the LAN (Proxmox,
Pi-hole, Sonarr/Radarr, qBittorrent, Jellyfin, an Ollama host, and a few smart-home bits). This
export is a frozen, front-end-only snapshot of that same UI with all the data swapped for mock
values, so it's safe to host and link to publicly.

## What's in the folder

- `index.html`, `404.html`, `404/` — the exported pages
- `_next/` — Next.js's built JS/CSS chunks and fonts for the static export
- `fonts/` — self-hosted Inter and JetBrains Mono woff2 files
- `camera-placeholder.jpg`, `ring-placeholder.jpg`, `mac-mini.png`, `icon.svg` — static image
  assets used by a few widgets (IP camera feed, Ring doorbell, and the Mac mini rack graphic)
- `scratch-map/countries.geo.json` — GeoJSON world map data used by the "scratch map" widget

## Design language

- **Dark theme**, widget-grid layout — each service/data source gets its own self-contained
  card (title, a stat or two, sometimes a small chart)
- **Tabs at the bottom** group widgets by category: Home, IoT, Infrastructure, Media, Projects
- **Recharts** for the line/area charts (CPU usage, disk I/O, DNS queries over time)
- Monospace (JetBrains Mono) for numeric/technical values, Inter for everything else

## What it isn't

- Not connected to anything real — no API routes, no server-side code, no credentials
- Not the source code for the dashboard itself, just its built, static output with mock data
- Not kept in sync automatically — it's a point-in-time export, regenerated by hand when the
  demo needs updating

## Where it's used

Embedded on my [personal website](https://github.com/Oisinruane/Personal_website)'s Homelab
Dashboard project page as a scaled-down, click-to-reveal preview.
